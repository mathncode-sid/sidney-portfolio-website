# Sidney Muriuki Portfolio

Source for [math-n-code-sid.dev](https://math-n-code-sid.dev), a static portfolio for Sidney Muriuki.

## Contents

- Professional summary and contact form
- Project summaries and case studies for LifeLine+, Hybrid GNN Fraud Intelligence, and Learn PostgreSQL
- Experience and community work
- `robots.txt` and `sitemap.xml` for search-engine discovery

## Local preview

Open `index.html` with a static server, for example:

```powershell
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Structure

```text
assets/     Images and CV used by the site
projects/   Project case-study pages
index.html  Portfolio homepage
styles.css  Site styles
robots.txt  Crawl rules
sitemap.xml Sitemap for the deployed site
```
